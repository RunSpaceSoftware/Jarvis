Missions are persistent goals. Jarvis wakes on its own, takes real actions with tools, updates progress, and reports to Telegram — even while you sleep.

DEPLOY A MISSION

Autopilot must be on (Settings) for background wake-ups.

HOW IT RUNS
  1. Wake-upEvery few minutes Jarvis reloads the mission, its notes and its memory.
  2. ActIt uses shell, files, research, skills and MCP tools — the same harness you use in chat.
  3. ReportProgress notes go to the HUD and to Telegram. Reply there to steer it mid-flight.
  4. FinishWhen the definition of done is met it marks the mission complete and pings you.

SANDBOXWORKSPACE SCOPE

File tools cannot read or write outside this folder. Commands run without a shell, so pipes, redirection, && and variables are not interpreted. Allowed programs can still reach outside paths — only allow tools you trust.
