# Research skill

1. Restate the question as 2-4 concrete sub-questions.
2. Run `web_search` for each sub-question. Prefer primary sources and recent material.
3. Open the 2-3 most promising results with `web_fetch`. If a page is blocked, try another source.
4. Cross-check any surprising claim in a second independent source.
5. Write the answer with inline source URLs. Mark anything unverified as unverified.
6. Save durable findings with `remember` using tags like `research,<topic>`.

Do not invent numbers, dates, or quotes. A missing answer is better than a fabricated one.
